1.0.0で変更したのはUI配色、アイコンの表示方法、文書、製品バージョンであり、暗号形式・Native Wi-Fi処理・選択バックアップ／復元処理は変更していない。このため1.0.0確定時は共有VMラボを再占有せず、全9台の上記証跡を互換性記録として維持し、ホスト上のAnyCPU／x86／x64再ビルドと回帰試験を実施した。

## 除外した途中結果

`YWB-Win7SP1-x64-Clean`の初回試験は、別作業とのGuestControl競合を検出したため中断し、結果を破棄した。

競合解消後の再試験ではx86回帰テスト24/24まで進んだが、Windowsエラー1062を旧検証プローブが未処理例外にし、ダイアログ待ちでタイムアウトした。この結果も互換性合否には数えず、サービス停止をAPI到達として扱う修正版で全9台を最初から再実行した。

## 実データ境界

ホストPCの実Wi-Fiプロファイルを使ったバックアップ／復元は、利用者の明示承認なしに実施しない。VM検証もNIC無効、合成プロファイル限定とする。
